## Tasks

### Task 1 — Framing, normalization and the denominator (KEY-03, KEY-04, KEY-05)

Add three checks to `offchain/test/Main.hs`, registered in `core_checks`:

1. `framing_separates_what_concatenation_conflates` — pick two component lists that render
   **identically under `BS.concat`** and differently under `frames`. Use
   `[("a","bcd"),("e","f")]` vs `[("ab","cd"),("e","f")]`: both are `abcdef` bare. Assert the
   `frames` outputs differ. **Do not substitute a pair built from fixed-length digests** — those
   differ bare too, so the check would pass with the framer deleted.
2. `edge_normalization_is_single_pass` — the same shock expressed `28e18` and
   `28000000000000000000` yields the same `content_key`.
3. `the_pips_denominator_is_in_the_preimage` — `key_preimage` with `pips_denominator` at 1000000
   vs 1000001 gives different bytes.

### Task 2 — The refusing identity and the shared renderer (KEY-01, KEY-02, KEY-06)

Add three more checks:

4. `key_identity_refuses_an_absolute_model_source_path` — `key_identity` on a `ToolchainIdentity`
   whose `ti_model_sources` carries an absolute path returns `Left`, and the error names the path.
   *(Digest the CONTENT, never the path — an absolute path makes the key machine-specific, so the
   same shock on another box misses the cache forever, silently.)*
5. `key_identity_refuses_an_absent_conopt_version` — `ti_conopt_version = Nothing` returns `Left`
   naming the field. *(Phase 24 built a version that cannot be constructed empty, then wrapped it
   in a `Maybe`; `Nothing` reaching the preimage is that hole one constructor up.)*
6. `the_preimage_excludes_every_per_run_token` — assert the preimage contains none of the tokens
   that vary per run: the `curdir=` prefix, the absolute timeout binary path, the `-k` flag and the
   budget. **This is the check that stops the store being useless** — `Gams.Run.spawn_into` puts a
   per-run exclusive temp dir in `wrapper_argv`, and a preimage that includes it gives a cache hit
   rate of exactly zero while every other key check still passes.

   Build the forbidden tokens from string fragments rather than spelling them literally, so the
   GAMS-free structural grep over `Main.hs` stays at 0.

`cabal test`, capturing each command's **own** exit code — do not take a pipeline's status from
`tail`, and do not gate on `grep -c`, which exits 1 on a zero count.

Expect **157/157** (151 + 6). Confirm zero warnings, both structural greps still 0, and
