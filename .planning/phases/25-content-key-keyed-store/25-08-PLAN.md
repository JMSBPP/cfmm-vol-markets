<objective>
The three exhibits whose pass condition is an ABSENCE, driven against a real server with the control
that makes each absence mean something.

Purpose: **STORE-08 is the sharpest trap in the phase.** "A partial or failed run never becomes a
cache entry" is green when the store is switched off, when the connection is dead, when the table
does not exist and when the insert path was never called — the empty-log `grep -q` shape this
repository has already been bitten by. The only instrument that fixes it is 24-06's: a POSITIVE
CONTROL THAT LANDS, evaluated FIRST, counted by the server itself. The same asymmetry applies to
quarantine: `quarantine_rows_after == 1` proves nothing without an AGREEING re-solve adding ZERO
rows, or the guard is satisfied by a quarantine that records everything.

**Decision of record, taken here:** the preimage is NOT stored in `model_run`. It is derivable from
the shock and the identity, and a digest recorded beside the thing it digests is the tautology this
repository has been bitten by (`Store.Types.volume_path_golden_sha256`'s haddock states the rule).
The capture records the computed preimage digest and the argv token list it describes, and the check
asserts the argv carries no per-run token. Record this decision and its reason in the summary.

Output: three new observation blocks, a re-taken artifact, and six Tier-C checks.
</objective>
