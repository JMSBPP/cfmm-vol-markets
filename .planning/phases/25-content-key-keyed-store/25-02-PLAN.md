    data ShockError

      | DuplicateField String
      | UnknownField String
      | FieldNotParseable String ArgvError

    only the first of three has to guess the rest — so collect ALL violations of each kind into the

      says which of seven inputs was wrong rather than that one of them was.

    cannot be omitted from a record so the criterion was previously unrepresentable rather than
    satisfied, and that the range refusals stay in `render_argv` — one refusal, one place.

    required.
