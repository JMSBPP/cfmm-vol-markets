## Tasks

### Task 1 — `Store.Solver`: the seam

Create `offchain/lib/Store/Solver.hs` exporting a `Solver` record of functions and a
`ProverOutcome` sum with at least `Produced` and the abort variants (non-zero exit, timeout,
exit-0-with-no-artifact). Add to the `.cabal`, to `aeson_storage_path`, and re-measure the floors.

The point of the seam is that elision can be **observed** without spawning GAMS: a test `Solver`
can count its own invocations. Do not import `Gams.Invoke` here — `cabal test` must stay GAMS-free.

### Task 2 — `Store.Cache.decide` and the elision checks (STORE-01)

Create `offchain/lib/Store/Cache.hs` exporting `decide`, which:

1. looks the key up **first**;
2. on a hit returns `Elided` with the **stored** bytes and never calls the solver;
3. on a miss calls the solver, and persists **only** a completed run.

`decide` takes a `KeyIdentity`, never a `RunRequest` — a per-run field reaching the key is what
makes the hit rate zero. Assert this structurally: `grep -c 'RunRequest' offchain/lib/Store/Cache.hs`
is 0.

Add two checks:

7. `an_identical_shock_elides_the_solve` — seed a `Store.Memory` with bytes **B**, then `decide`
   with a solver that would return different bytes **B′** and increments a counter. Assert the
   result is **B** (not B′) **and** the counter is 0. *Asserting the value as well as the counter
   is what distinguishes real elision from a solver that ran and was ignored.*
8. `a_miss_invokes_the_solver_exactly_once` — the same, against an empty store: counter 1, and the
   stored bytes afterwards are the solver's.

### Task 3 — Abort safety (STORE-08)

9. `an_aborted_run_produces_no_cache_entry` — drive each abort variant against a **fresh**
   `Store.Memory` and assert the store is empty afterwards.

   **Absence is the pass condition here, which is the shape that most often passes vacuously.** So
   order a `Produced` positive control FIRST in the same check and assert `entries == 1` from the
   store's own count. If the control does not land, the check fails — that is what stops "the store
   is empty" from being satisfied by a store that never worked at all. This one positive control is
   kept deliberately; it is not the blanket per-claim discipline that was cut.
