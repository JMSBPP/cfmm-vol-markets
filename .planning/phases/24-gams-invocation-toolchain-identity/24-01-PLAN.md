<decisions_of_record>
These are decided here so no later plan re-opens them. Each is derived from a MEASURED value in
`24-RESEARCH.md`.

1. **Subprocess library is `process` 1.6.26.1 (+0 packages).** MEASURED draining 2,000,000 bytes
   of stderr with no deadlock. `typed-process` is +2 packages (MEASURED by `plan.json` set-diff,
   158 → 160) and buys `ByteString` streams, which decision 2 makes unnecessary.
2. **`lo=2`.** The prover writes its log to `<rundir>/volume_path.log` and leaves stdout and
   stderr at 0 bytes. Versions are read from that FILE with `Data.ByteString.readFile`, never from
   a stream, so no locale decoder touches a banner.
3. **Temp directory is hand-rolled on `directory` (+0).** `withSystemTempDirectory` is in
   `temporary`, which is NOT in this build plan. `createDirectory` FAILS if the path exists, and
   that exclusivity is the stale-file defence.
4. **Timeout is `/usr/bin/timeout -k 5 <budget>` as the DIRECT child**, with a Haskell
   `System.Timeout.timeout (budget + slack)` backstop. `timeout(1)` signals the process GROUP;
   `terminateProcess` reaches the direct child only and MEASURED leaves the grandchild alive at
   PPID 1 — and GAMS runs CONOPT at `Solvelink=2` as a separate process, so the grandchild is the
   real case.
5. **Two IO modules, not one.** `Gams.Run` is the testable IO edge and takes the binary path,
   model path, argv, environment, budget and run directory ALL EXPLICITLY. `Gams.Invoke` is the
   thin composition that resolves the REAL binary from `Gams.Config` and calls `Gams.Run`; it is
   imported ONLY by `offchain/app/GamsConformance.hs`. This is what makes the GAMS-free structural
   grep (plan 24-04) coherent: `cabal test` may drive the invocation layer against stubs and still
   be structurally incapable of naming the real prover.
6. **`default_gams_bin = "gams"`, not an absolute path.** The absolute path and the binary's
   sha256 are MACHINE-SPECIFIC (`79cd3a57…`, 1,822,256 bytes on this machine); pinning either in
   Haskell source would make `cabal test` fail on every other install. They are RECORDED in the
   capture artifact and asserted on shape.
</decisions_of_record>

    `parse_gams_version model_basename bytes`:
    - decode with `Data.Text.Encoding.decodeUtf8'`; a decode failure is `Left NoJobBanner`, never
      an exception;

    - find the FIRST line beginning `"--- Job "`; if none, `Left NoJobBanner`;
    - the job name is the whitespace-delimited token after `"--- Job "`. If it does not equal
      `model_basename`, `Left (WrongJob job_name)`. **This one rule rejects both wrong-subject
      banners without a denylist** — `?` for the no-argument form and `--version` for the flag;

      `Left MissingVersionField`;

      `Left (MalformedVersion tok)`.
