<objective>
The one IO edge, and the four conjuncts that make "the prover succeeded" mean something.

Purpose: GAMS's own documentation says exit `0` means "GAMS ran", not "the model solved" — and this
was MEASURED twice with the real binary: `action=c` exits 0 and writes no artifact, and `gams` with
no arguments at all exits 0 and runs no model. A layer that reports success on exit 0 alone is this
repository's recurring defect wearing a new representation. This plan makes the verdict a
conjunction of exit code, artifact presence in a directory that could not have pre-existed, artifact
freshness, and the artifact's own post-conditions — none of which is log text.

Output: `offchain/lib/Gams/Run.hs`, a stub-writing helper, and five Tier-B checks that spawn real
subprocesses against shell stubs the checks write themselves. `cabal test` stays GAMS-free.
</objective>

    data RunRequest = RunRequest
      { rr_binary   :: !FilePath   -- ABSOLUTE. Rejected if relative: a PATH-resolved name is a shadow surface.
      , rr_model    :: !FilePath   -- ABSOLUTE path to the .gms
      , rr_shock    :: !Shock
      , rr_env      :: !(Maybe [(String, String)])  -- Just whitelist in production; Nothing only in a check
      , rr_budget_s :: !Int        -- seconds handed to timeout(1)
      , rr_kill_after_s :: !Int    -- the -k grace
      }
    data ToolchainIdentity = ToolchainIdentity
      { ti_gams_version   :: !GamsVersion
      , ti_conopt_version :: !(Maybe ConoptVersion)  -- Nothing when the run did not reach the solver
      , ti_gams_path      :: !FilePath
      , ti_gams_sha256    :: !String        -- BARE hex
      , ti_model_sources  :: ![(FilePath, String)]   -- sorted (path, sha256)
      }
    data CapturedStreams = CapturedStreams
      { cs_stdout :: !BS.ByteString, cs_stderr :: !BS.ByteString, cs_log :: !BS.ByteString }

    The invocation, in order:

    1. `render_argv` the shock; a `Left` is `Aborted (ArgvRejected e) 0` with no process spawned.
    2. `with_fresh_run_dir` — `getTemporaryDirectory`, then `createDirectory` on
       `<tmp>/cfmm-gams-run-<pid>-<counter>`. `createDirectory` FAILS if the path exists and that
       exclusivity IS the stale-file defence; a name that silently reused an existing directory
       would reopen the hole. `bracket`ed with `removeDirectoryRecursive`, so the directory is gone
       on EVERY path including an exception.
    3. Record `t0 <- getModificationTime` of a marker file written into the fresh directory
       immediately before the spawn (or `getCurrentTime`), for the freshness conjunct.
    4. Spawn, with `readCreateProcessWithExitCode` over a `CreateProcess` carrying
       `cwd = Just run_dir` and `env = rr_env`:
       ```
       "/usr/bin/timeout" : "-k" : show rr_kill_after_s : show rr_budget_s
         : rr_binary : rr_model : "action=ce" : ("curdir=" ++ run_dir) : "lo=2" : argv
       ```
       `readCreateProcessWithExitCode` forks two draining threads — MEASURED swallowing 2,000,000
       bytes of stderr with no deadlock — so the pipes are drained by construction. Wrap the whole
       call in `System.Timeout.timeout ((rr_budget_s + 5) * 1000000)` as a BACKSTOP for the case
       where `timeout(1)` is itself missing; a `Nothing` from the backstop is
       `Aborted (ExitVerdict (TimedOut Killed))`.
    5. `classify_exit` the wrapper's exit code. Anything other than `Solved` is
       `Aborted (ExitVerdict v) code streams` — and note in the comment that `TimedOut Expired`
       arrives here as plain exit 124 from `timeout(1)`, which is why the taxonomy has to carry it.
    6. Exit 0 is the FIRST conjunct. Then, in order:
       a. `<run_dir>/volume_path.json` exists, else `Aborted NoArtifact`;
       b. its modification time is at or after `t0`, else `Aborted StaleArtifact`;
       c. `decode_artifact` its bytes read with `Data.ByteString.readFile` (never
          `Prelude.readFile`: `String`, locale-decoded, newline-translating), else
          `Aborted (ArtifactRejected e)`;
       d. every echoed string field equals the argv token that was SENT — compare
          `pa_sqrt_price_x96_text` and `pa_liquidity_text` to the tokens produced by `render_argv`,
          else `Aborted (EchoMismatch field sent got)`;
       e. `parse_gams_version (takeFileName rr_model)` over `<run_dir>/volume_path.log`, else
          `Aborted (VersionUnreadable e)` — **detection that finds nothing ABORTS the run**;
       f. `parse_conopt_version` over the same log; `Nothing` is permitted here and ONLY here,
          because a run that aborted before the solve legitimately has no CONOPT banner — but that
          case is unreachable from a `Produced` outcome, so record it as `ti_conopt_version` and
          let the capture assert it is present on the clean path.
    7. `ti_gams_sha256` is `Store.Types.sha256_hex` of the resolved binary's bytes, rendered BARE
       (a `0x`-prefixed 64-hex literal anywhere under `offchain/` reddens `sc3_literal_purge`).
       `ti_model_sources` is the sorted `(path, sha256)` LIST, not a single digest — `volume_path.gms`
       has **0 `$include` directives today** (VERIFIED at plan time by
       `grep -cE '\$include|\$batinclude|\$libinclude'`), so the list has one element now and a
       future include is covered without a code change.

    **NO decision in this module may read a stream.** `cs_stdout` and `cs_stderr` are carried for
    DIAGNOSIS only, and the module must say so in a comment beside the field. Forbidden tokens
    anywhere in this file: `isInfixOf`, `infeasible`, `optimal`, `Locally`, `Normal completion`,
    `Status:`. `lo=2` also makes this structurally easy — MEASURED, both streams are 0 bytes and
