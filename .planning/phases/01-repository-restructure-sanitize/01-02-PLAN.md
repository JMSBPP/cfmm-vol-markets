    The baseline branch is pinned EXPLICITLY to `master` (do NOT use `git branch --show-current`).

    ```bash
    BASE=master

    # 1. Push the clean baseline to the existing PRIVATE JMSBPP repo (still private; reversible)
    git push --force origin "$BASE"

    # 2. [PRE-TRANSFER LEAK GATE] Prune every NON-baseline branch + tag so the transfer ships only the sanitized master.
    #    Local non-baseline branches (KEEP backup/pre-squash as the recovery point — it is never pushed):
    git for-each-ref --format='%(refname:short)' refs/heads \
      | grep -vx "$BASE" | grep -vx 'backup/pre-squash' \
      | xargs -r -n1 git branch -D
    #    Local tags:
    git tag | xargs -r -n1 git tag -d
    #    Remote non-baseline branches:
    git ls-remote --heads origin | awk '{print $2}' | sed 's#refs/heads/##' \
      | grep -vx "$BASE" | xargs -r -n1 -I{} git push origin --delete {}
    #    Remote tags:
    git ls-remote --tags origin | awk '{print $2}' | sed 's#refs/tags/##' \
      | grep -v '\^{}' | xargs -r -n1 -I{} git push origin --delete "refs/tags/{}"
    #    HARD GATE — immediately before transfer, the remote must hold exactly one branch and zero tags:
    [ "$(git ls-remote --heads origin | wc -l)" = "1" ] || { echo "ABORT: remote has stray branches"; exit 1; }
    [ -z "$(git ls-remote --tags origin)" ]            || { echo "ABORT: remote has stray tags"; exit 1; }

    # 3. [IRREVERSIBLE] Transfer the repo into the wvs-finance org (JMSBPP is admin)
    gh api -X POST repos/JMSBPP/cfmm-replicationPlank/transfer -f new_owner=wvs-finance
    #    confirm the transfer landed before continuing:
    gh repo view wvs-finance/cfmm-replicationPlank --json name --jq .name   # expect: cfmm-replicationPlank

    # 4. [IRREVERSIBLE] Flip the canonical repo PUBLIC
    gh repo edit wvs-finance/cfmm-replicationPlank --visibility public --accept-visibility-change-consequences
    #    optional metadata (Claude's discretion): description from PROJECT.md "What This Is"
    gh repo edit wvs-finance/cfmm-replicationPlank --description "Open-loop plumbing connecting a GAMS CFMM model to a Plank (EVM) implementation via a fixed-point encoding contract."

    # 5. [IRREVERSIBLE] Fork the canonical back to JMSBPP (recreates JMSBPP/cfmm-replicationPlank as a fork)
    gh repo fork wvs-finance/cfmm-replicationPlank --clone=false

    # 6. Set local remote topology: origin -> JMSBPP fork, upstream -> wvs-finance canonical
    git remote set-url origin https://github.com/JMSBPP/cfmm-replicationPlank.git
    git remote remove upstream 2>/dev/null || true
    git remote add upstream https://github.com/wvs-finance/cfmm-replicationPlank.git
    ```

    If the fork (step 5) reports the fork already exists or is still propagating, poll `gh repo view JMSBPP/cfmm-replicationPlank --json isFork --jq .isFork` until it returns `true`.
