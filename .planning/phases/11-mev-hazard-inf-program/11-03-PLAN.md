Land bundle A's returned proof: download, verify nothing previously proven was touched, integrate
with the inverse import rewrite, register the module, build, sweep axioms, diff every returned
statement against the T1-T19 checklist, and push to both remotes.

silent no-build, a modified pre-existing module invalidates every prior verification, and an
un-diffed return lets a quietly weakened theorem pass as the claim the doc makes.
