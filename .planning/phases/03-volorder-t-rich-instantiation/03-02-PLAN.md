## The one thing that must not be got wrong

`panoptic_add_asset` is **additive** (`PanopticTokenId.plk:26`):

```plank
const panoptic_add_asset = fn (tid: u256, v: u256, leg: u256) u256 { tid +% @evm_shl(64 +% (leg *% 48), v & 0x1) };
```

`vol_order_to_mint` already adds `asset = 1` on all four legs (`PanopticTokenIdSetterLib.plk:155-158`).
If the Layer-1 write is added while those four survive, the second add **carries out of bit
`64+48k` into bit `64+48k+1` — which is `optionRatio`'s least significant bit.** No revert; a
plausible wrong number. And the golden vectors cannot catch it, because they call Layer 1 only
(`VolOrderToPanopticTokenId.t.sol:99`, `tokenIdFromVolOrder`). Only the mint path's single
`_optionRatio` assertion would, and only by luck.

**Therefore Task 1 and Task 2 below are ONE COMMIT.** Not two. This is VORD-08.

```plank

    // operands live; this is the only place in the codebase that follows it into region T.
    //
    // The spine is "the caller declares, the contract proves": every redundant field in the payload
    // is checked against a value derived independently here, and a disagreement REVERTS. A proof
    // that discards its input is not a proof. Accepted cost: a caller can brick a valid order by

        tid = panoptic_add_option_ratio(tid, extra_payload_option_ratio(payload, 1), 1);
        tid = panoptic_add_option_ratio(tid, extra_payload_option_ratio(payload, 2), 2);
        tid = panoptic_add_option_ratio(tid, extra_payload_option_ratio(payload, 3), 3);

        // tokenType is REDUNDANT AND CHECKED: the geometry above already wrote (0,0,1,1) from the

        require(extra_payload_token_type(payload, 0) == 0);
        require(extra_payload_token_type(payload, 1) == 0);
        require(extra_payload_token_type(payload, 2) == 1);
        require(extra_payload_token_type(payload, 3) == 1);

```

**C. Add the region read.** Add a small helper above `vol_order_to_panoptic_token_id`. The read
mechanism is Claude's discretion per `03-CONTEXT.md`; the simplest form that stays inside attested
ground is a comptime `if` on the region tag, which IS an expression in `let` position — attested at
`std/regions.plk`'s `keccak256`:

```plank
// The ONE region-branching read in this file. `Slice(T, u256, Some(4))` is deliberately NOT used:
// the payload is ONE packed 40-bit word, not four elements, so a 4-element slice is the wrong shape.
const payload_word_in = fn (comptime T: type, offset: u256) u256 {
    if T == calldata {
        @evm_calldataload(offset)
    } else if T == memory {
        @mload32(offset)
    } else {
        @compile_error("payload_word_in: T must be calldata or memory")
    }
};
```

Add `import std::regions::{calldata, memory};` if `memory` is not already imported, and
`import std::option::{is_none, unwrap};` and the `Extra` payload accessors from `types::Extra::*`.
