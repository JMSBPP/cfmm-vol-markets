Rules that are part of the contract:
- **Every hex string is lowercased** (`tr 'A-Z' 'a-z'`) — research §7.2: broadcast JSON is
  lowercase, `console.log` renders EIP-55 mixed case. Normalising unconditionally makes the
  cross-check correct under either rendering and makes the Haskell side's `==` honest.
- **No key is optional and no value is `null`.** A missing address is a generation failure, not a
  `null` to be papered over downstream (research §5.2 anti-pattern).
- `tickSpacing`, `initTs`, `initTick` and `chainId` are JSON **numbers**, not strings.
- `generatedAt` is the ONLY field allowed to vary between two runs — SC-5 compares
  `jq -S 'del(.generatedAt)'`.
