manifest, and stand up the cabal test-suite that proves the pins are a consumption of the interface
files rather than a transcription of them.

signature strings would reproduce exactly that failure one layer up (research §5.6), so the
interface FILE is the test's input.

and `offchain/rig/README.md`.
