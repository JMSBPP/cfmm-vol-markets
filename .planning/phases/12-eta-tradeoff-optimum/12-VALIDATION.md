| **Doc fidelity** | `sha256sum` pin + E-block byte diff (approved vs bundled vs returned-bundle copy), all extractions END-marker-delimited (`**E0.` .. `<!-- END ETA -->`), placement-independent |
| **Statement fidelity** | whitespace-normalized diff of every `T1'…T31'` block against the sha-pinned prompt |
| **Estimated runtime** | ~11 s incremental; ~30 s for a new module's first elaboration |

Two verification layers run in this phase, and they are not interchangeable:

1. **Machine-checked layer** — `lake build` exit code plus the generated axiom sweep. Green builds
   are only meaningful once the module is registered as a lakefile root; the integration plan
   verifies the `Built vol_markets.EtaCurvature` log line for exactly that reason, and the root
   count is checked with `grep -o 'vol_markets\.[A-Za-z]*' | wc -l` (occurrences), never `grep -c`
   (lines — the roots list spans ~6 lines).
2. **Fidelity layer** — a statement-by-statement diff of every returned signature against the
   sha-pinned prompt, including the anti-narrowing watch list (strictness, whole-interval maximum,
   the T24' equality, the constructed T27', the T29' conjunction, T30' referencing the prior
   theorems' statements, the T28'a/T28'b separation). A quietly weakened theorem passes layer 1
   and fails layer 2; the record (`12-03-FIDELITY.md`) is a committed artifact.

  notation gate PASS, both remotes pushed and verified fast-forward
