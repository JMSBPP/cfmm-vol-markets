# Plan 27-02 — The pinned read layer

## Context

**MEASURED: block pinning is absent.** One `"latest"` tree-wide, no `BlockRef` type anywhere, and
`CheatSwap/Rpc.hs:151` reads `GlobalState.blockNumber` with no pin. This plan builds the thing, it
does not adjust one.

**CHAIN-02's obvious test cannot fail.** On a single-writer local anvil, a pinned read and an
unpinned read return the same value in every recorded field — the defect is invisible unless the
divergence is **constructed**. So the observation is: read at block *b*, mine blocks, change the
pool state, then assert the **pinned** read still returns the block-*b* value **while the unpinned
read returns the new one**. If the unpinned read does not differ, the test proved nothing and must
say so rather than pass.

**CHAIN-03 is the zero-word trap.** The repo has hit it repeatedly: the zero address passing
hex-shape guards, a numeric zero passing a non-emptiness test, `"" == ""`. A pool read returning
`0` for liquidity or `0x00…00` for a slot is **shape-valid and meaningless**, and it must be an
error naming the field, not a value that reaches a content key.

## Tasks

### Task 1 — `Chain.Read`: pinning by construction

Create `offchain/lib/Chain/Read.hs`:

- `newtype BlockRef = AtBlock Integer` — **no `Latest` constructor.** Not "we avoid Latest"; the type
  cannot express it. That is what makes the grep assertion honest rather than aspirational.
- Read functions taking `BlockRef` as a **required positional argument**: sqrt price, liquidity, fee.
  There must be no arity at which a caller omits it and no default.
- Each read records the block it was **made at**, and an unpinned tag surfaces as `null` in the
  artifact rather than as a plausible height — the existing `readback_height` idiom.
- Refusals name the field: an absent, zero, or unparseable value is `Left` carrying the field name.

Join `aeson_storage_path` **in this task**; re-measure both floors from what `find` PRINTS.

### Task 2 — Tier-A and Tier-B checks (CHAIN-03, and CHAIN-02's structural half)

Register in `core_checks`:

1. `no_read_can_omit_its_block` — assert every exported read's type mentions `BlockRef`, and that
   `Chain/Read.hs` contains no default block value. **Anchor the pattern to what it means** — a bare
   `latest` matches prose; three gates in phase 26 could never have printed their required value for
   exactly this reason. Use `\blatest\b` case-insensitively and check the pattern against the file
   before relying on it.
2. `latest_appears_nowhere_in_the_read_layer` — with a **proven positive control**: seed the token
   into a scratch copy and observe the scan match, so absence is shown to be detectable before it is
   claimed.
3. `a_zero_or_absent_read_is_refused_by_field_name` — drive each of: liquidity `0`, sqrt price `0`,
   an all-zero word, an unparseable hex string, an absent key. Assert each returns `Left` and that
   the message **names the field**. Assert a longer wrong value cannot satisfy the naming arm —
   26-03 observed a naming arm PASS because `"828040"` contains `"82804"`, and there are 68
   `isInfixOf` uses in this suite.

### Task 3 — The capture, out of band (CHAIN-02's real observation)

Write `offchain/rig/capture-chain-read.sh`:

- resolve the endpoint via 27-01's rule; **fail loudly and by name** if no anvil answers — never skip
- stand the pool up with the existing `deploy-rig.sh` (it deploys a real v4 pool; it does **not**
  deploy the Shock writer, which is CHAIN-01's blocked dependency and not needed here)
- read pool state at block *b*; mine blocks; change the state; read again **pinned to *b*** and
  **unpinned**
- record: `pinned_value`, `unpinned_value`, `pinned_equals_block_b`, `unpinned_differs`, the heights,
  and the chain id
- write `offchain/rig/chain-read-conformance.json`

Then a check asserting over that artifact, including **`unpinned_differs == true`** — if the
unpinned read did not move, the capture did not construct the divergence and the evidence is void.
That assertion is what stops the whole capture passing vacuously on a quiet chain.

**`cabal test` must stay chain-free.** Add a third structural grep beside the DB-free and GAMS-free
ones, asserting `Main.hs` never names the RPC transport or `CFMM_REQUIRE_CHAIN`, with a proven
positive control.
