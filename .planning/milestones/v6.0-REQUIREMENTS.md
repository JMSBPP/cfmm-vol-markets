## v1 Requirements

### Writer / EVM execution (EXEC)

- [ ] **EXEC-01**: The writer settles each swap leg via `algebraSwapCallback`, paying the pool the
  positive deltas using hookData-supplied tokens (negative delta = received, pays nothing).
  *(landed as plank-compile draft — `589c6d6`; validated CALLED-green under INTG-01)*
- [ ] **EXEC-02**: A generic `multicall(address pool, bytes[] calls)` batch executor runs a
  sequence of pre-encoded pool calls, reverting on any failure. *(→ #27)*
- [ ] **EXEC-03**: The writer registers as an Algebra plugin with the `beforeSwap` flag set **and**
  implements the `beforeSwap` hook, so flagged swaps execute without reverting on an unimplemented
  hook.
- [ ] **EXEC-04**: The pool executes fee-free swaps (fee 0, asserted) so the on-chain price path
  matches the model's full-`dQx` recursion — fees are accounting overlays, never skimmed from the
  price-moving amount (VOLUME_PATH.md §6.3).

### Toolchain (TOOL)

- [ ] **TOOL-01**: The plank compiler is pinned to the local `plank_dev` build (`.plank-version` +
  Makefile `PLANK`), so `plank build` is reproducible and the stale PATH `v0.1.1` is retired.
- [ ] **TOOL-02**: The Solidity/Algebra suite compiles and runs under `--via-ir` (the pre-existing
  solc SIGSEGV resolved), so `forge test` executes. *(distinct from TOOL-01: a solc crash, not a
  plank-compiler issue)*

### Integration (INTG)

- [ ] **INTG-01**: The VolumePath differential test drives the `dQx` path through the writer's
  multicall and asserts `tickBefore == tickAfter` CALLED-green, with per-swap full-consumption
  (an under-fill = the path left the liquidity band = loud failure). *(completes #24; the temporary
  test-side `algebraSwapCallback` + `address(this)` mint are deleted here)*
- [ ] **INTG-02**: The model's build foundation (`lib/Algebra`, `DeployAlgebraFactory.s.sol`, the
  spec) is tracked in git, so the model builds outside this working tree (prerequisite for any
  develop migration).
