## M41 — Theorem 53, the equating

**(a).** With the monoid identity `1-φ* = (1-φ_M)(1-φ_X)(1-τ)` in hand,
`τ = 1 + (1-φ_X)/S` iff `S = -(1-φ_X)/(1-τ)`, and that value equals
`-(1-φ_M)(1-φ_X)²/(1-φ*)`. The author's hand derivation is right. It is the
`MevLVRCancellation` bracket zero restated **only in the composed slot**: with
`(1-φ_M)(1-τ)·∂φ_X/∂ν` in the gate position the literal bracket vanishes exactly
when the FOC core does. In the **bare** slot — the slot
`MevTaxProgram.Proposition16_corrected_law` actually uses — the two objects
differ by `(1-(1-φ_M)(1-τ))·(∂φ_X/∂ν)(∂ν/∂τ)`, and they coincide for all slope
values iff `(1-φ_M)(1-τ) = 1`, i.e. only in the trivial no-tax/no-fee corner.

**(b).** Not an identity. Which of (ii) and (iii) holds is decided by the flag
of (d):

* **Off-loop** (`∂ν/∂τ` an unconstrained datum, which is what the typed
  signature of `MevTaxProgram.totalDeriv` offers): **(ii) codimension one**.
  The FOC core is affine in the slope with nonzero coefficient `(1-τ)∂φ_X/∂ν`,
  so exactly one slope value per parameter point satisfies the equating —
  `∂ν/∂τ = -(1-φ_X)/((1-τ)∂φ_X/∂ν)`. On-locus witness: `φ_M = 0`,
  `φ_X = 1/4`, `φ* = 1/2`, slope product `(9/8)(-1)`, both laws return `1/3`.
  Off-locus witness: same point with slope product `1·(-1)`, giving
  `τ*_law = 1/4 ≠ 1/3 = τ*_topup`. The parameter point is a genuine interior
  optimum of the extended model (`φ*= 1/2` solves the reduced FOC with
  `q = 5/4 > 0`).
* **Loop-consistent** (ν generated by the composed fee, i.e. the corpus's own
  model, `SRC` Theorem 37): **(iii) impossible**. The FOC core equals
  `(1-φ_X)/ℱ` with `ℱ > 1`, hence is strictly positive at every tax; the total
  derivative never vanishes; `τ*_law` does not exist, so there is nothing to
  equate.

**(c).** Conditional on the corrected law holding at `τ`, `∂ν/∂τ` is pinned in
protocol observables, `∂ν/∂τ = -(1-φ_X)/((1-τ)·γ_R(φ_X-φ̄)(1-u/α_R))`, with the
gate derivative supplied in closed form by Theorem 54(a) — everything on the
right-hand side is protocol-known except `τ` and `φ_X`, both observable. **What
dies if (b) reads (iii):** the hypothesis is unsatisfiable at every `τ < 1`, so
the pinning is vacuous and cannot be used to calibrate `∂ν/∂τ`. The calibration
reading is therefore only as good as the off-loop ν.

**(d).** The flag is load-bearing and we do not rule. With a block-type-weighted
realized ν (Rule 13), `ν = w·ν_arb + (1-w)·ν_trans`, whose transactional leg is
exogenous, the corrected law **has** a root at parameters where Theorem 36's
arb-only ν has none. So (b)'s verdict, (c)'s non-vacuity, and the calibration
programme all hinge on this choice. **A further author ruling is required.**

## M42 — Theorem 54, the explicit gate derivative

**(a).** `∂φ_X/∂ν = S(σ)·γ_R·u·(1-u/α_R) = γ_R(φ_X-φ̄)(1-u/α_R)`, with `u` the
gate value of `DOC` Theorem 1, and this is a genuine `HasDerivAt` of the fee
level in ν. Composed via `SRC` Convention 9, the derivative of the total fee
carries the monoid Jacobian explicitly as `(1-φ_M)(1-τ)·γ_R(φ_X-φ̄)(1-u/α_R)`.

**(b).** The first guard conjunct is now a theorem: `0 < ∂φ_X/∂ν` iff
`φ̄ < φ_X` **and** `u < α_R`. The second half is automatic — `0 < u < α_R` holds
at every finite utilization, and saturation is a *limit* (`u → α_R` as `ν → ∞`,
`u → 0` as `ν → -∞`), never attained. So only "fee strictly above floor" is
substantive. **At the degenerate limit `∂φ_X/∂ν = 0`** the total derivative is
nonzero at every tax: `τ*_law` ceases to exist (the formal expression collapses
to `1`, which is not a root).

**(c).** `∂ν/∂φ < 0` on the participation region comes from
`MevTaxShock`'s explicit `ν = g`. Chained through
`Theorem29_monoid_path_is_direct` in the bare reading it gives
`∂ν/∂τ = (∂ν/∂φ)(1-φ_M)(1-φ_X) < 0`. **No obstruction:** the sign survives the
feedback term. Solving the self-consistent loop gives
`dφ/dτ = (1-φ_M)(1-φ_X)/ℱ` with `ℱ = 1 - (∂ν/∂φ)(1-φ_M)(1-τ)(∂φ_X/∂ν) > 1`, so
the response is damped but never sign-flipped, and `∂ν/∂τ = (∂ν/∂φ)(dφ/dτ) < 0`.
The same `ℱ > 1` is what forces Theorem 53(b) into (iii) under the loop reading:
the guard survives, the *root* does not.

**(d).** `∂φ_X/∂ν ≤ (γ_R α_R / 4)·Σ_j α_j` uniformly, from
`e^x/(1+e^x)² ≤ 1/4` and `S(σ) ≤ Σ_j α_j`. The constant is sharp: at the gate
midpoint (`u = α_R/2`) the derivative equals `(γ_R α_R/4)·S(σ)`.

## M43 — Theorem 55, computability of `φ*`

**(a).** The stationarity condition is an exponential against a **quadratic**:
`e^{-αφ}(αcφ² + ασφ - σ) = Lvr·σ/K`. Lambert `W` inverts `z·e^z` — an
exponential against a *linear* factor — so the reduction is available exactly
when the quadratic degenerates. Formally: at `c = 0` the FOC is equivalent to
`(1-αφ)e^{1-αφ} = -e·Lvr/K`, i.e. `φ* = (1 - W(-e·Lvr/K))/α`. For `c ≠ 0` the
quadratic factor blocks it.

**OPEN (with reason).** A *proof* that no elementary-or-Lambert closed form
exists for `c ≠ 0` is a differential-Galois / transcendence statement about the
solution as a function of the parameters; neither the differential Galois theory
nor the Lambert-class machinery needed to state it is available in Mathlib, and
building it is a project in its own right. We state the reduction and its
obstruction rather than narrow the claim.

**(b) — the artifact.** Because (a) is negative we deliver the iteration.
Abstract engine: for `Φ` with `-M ≤ Φ' ≤ -m < 0` on a sign-changing bracket
`[a,b]`, the root is unique, `T x = x + Φ(x)/M` maps `[a,b]` into itself, is
monotone there, and contracts with factor `1 - m/M ∈ [0,1)`; every iterate obeys

```
|T^[n] x₀ - φ*|  ≤  (1 - m/M)^n · (b - a)          for any x₀ ∈ [a,b].
```

Instantiated at the model's own reduced FOC on a bracket inside Theorem 52's
`q ≥ q_lo > 0` guard region, with the explicit constants
`m = K α e^{-αb} q_lo`, `M = K α e^{-αa}(2σ + 2cb)`, the ratio is
`K`-independent:

```
k = 1 - e^{-α(b-a)} · q_lo / (2σ + 2cb).
```

Non-vacuity is exhibited, not asserted: at the same parameter point as the
Theorem 53(b) interior optimum, on `[1/4, 3/4]`, every hypothesis holds and
`k ≤ 10/13`, so the error after `n` steps is at most `(10/13)^n·(1/2)` — a step
count the hook can fix in advance. Note `T` uses a *fixed* denominator `M`, not
`Φ'(x)`: no division by a derivative, no Newton divergence branch.

**(c).** The reduced FOC is nondecreasing in σ at every fee with `αφ ≤ 1`
(with `Lvr = σ²Δt/8` carrying its own σ-dependence). Pointwise domination lifts
to the iterates — from the same warm start, the lower-σ orbit stays below the
higher-σ orbit at every step — and to the limits, `φ*(σ₁) ≤ φ*(σ₂)`. This is
Theorem 50's pro-cyclicality, so warm-starting from the previous block moves the
right way.

*Caveat, stated:* the σ-monotonicity input carries the pointwise hypothesis
`αφ ≤ 1`, which `Theorem50d` does not need because it argues at stationary
points. Outside that region the pointwise comparison is not claimed.

**(d).** Three corner predicates, all numeral-free, all checkable before
iterating:

* **shutdown**: `K·c ≤ Lvr·σ` ⟹ the objective is strictly negative at every
  admissible fee;
* **corner at zero**: reduced FOC `≤ 0` already at the base fee ⟹ it stays `≤ 0`
  on the whole range, so `τ* = 0`;
* **interior**: a sign change between the base fee and an admissible upper fee
  certifies an interior `φ*`, and the induced tax `(φ*-φ_base)/(1-φ_base)` lies
  strictly in `(0,1)` and reproduces `φ*` through Theorem 50's top-up law.

Read together: read σ, evaluate the three predicates, and only in the interior
case iterate `T` to the machine-checked tolerance, then apply the top-up law.
